# HUD Comparison Criteria

## Judge Question

**Mid-fight stills and a damage-taken strip. Which HUD looks more polished and readable?**

## Pair Moments

**Pair 1:** Idle state with full HUD visible and no active threats. This shows the layout, spacing, and visual clarity of all UI elements when the player has time to read them.

**Pair 2:** Mid-combat with enemies on screen and action happening. This shows how well the HUD stays out of the way and how clearly the player can read critical information while focusing on the game world.

**Pair 3:** Motion strip showing damage taken and state changes. This demonstrates how smoothly and clearly the HUD communicates health loss, with animation polish and visual feedback under stress.
