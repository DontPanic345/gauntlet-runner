# Title Screen Judging Criteria

## Question

Which title screen makes you want to press Start? Judge on visual hierarchy, inviting presentation, clarity of the call-to-action, and overall polish.

## Pair Descriptions

**Pair 1: Initial Title Screen**
The first frame players see after loading. Which one draws you in and makes starting feel inevitable?

**Pair 2: Menu Navigation State**
How the UI presents itself as players navigate through menu options. Which approach feels cleaner and more inviting?

**Pair 3: Settings/Configuration Screen**
The interface for adjusting game options. Which design feels more polished and less overwhelming?
