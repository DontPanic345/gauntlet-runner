# Judging question

Still frames and a slow pan strip. Which one looks like a finished, beautiful game?

Answer `A`, `B`, or `tie` (a tie only if genuinely indistinguishable in quality).

# Pairs

1. Both panels: a still of a torch-lit dungeon room with the player character in it, interface hidden or almost hidden.
2. Both panels: a still of a combat moment in an arena, with the game interface visible.
3. Both panels: a still of an arena with no fight under way, interface visible, both shown at the same reduced source resolution (400x225, enlarged).
4. Both panels: a 12-frame strip at 7.5 fps of the player fighting in a dark, lit area, interface visible (read left to right, top to bottom).
5. Both panels: a 12-frame strip at 7.5 fps with the camera moving across a room during play (read left to right, top to bottom).
