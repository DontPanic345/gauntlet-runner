# Blind comparison: run flow and endings

**Question:** Strips of the death sequence, summary and victory. Which run loop feels more complete and replayable?

Judge A against B on each pair, then overall. "Complete" means the run has a clear ending in both directions (death and victory), the end of a run is marked as an event, and the player is told what happened in the run. "Replayable" means the end screens make you want another go and get you back into play quickly.

Strips are 12 frames read left to right, top to bottom.

1. both panels: the moment the player character dies, through to the first end-of-run screen, 12 frames at 300 ms intervals (from short live runs on both sides).
2. both panels: the end-of-run summary after a short run that ended in death (still, live capture).
3. both panels: the screen shown at the moment the run is won (still).
4. both panels: the end-of-run summary after a won run (still).
5. both panels: from the end-of-run summary, the player choosing to play again, through to being back in a new run, 12 frames at 250 ms intervals, input as fast as the screens allow.

Answer `A`, `B`, or `tie` per pair and overall. A tie must mean the two are genuinely indistinguishable in quality.
