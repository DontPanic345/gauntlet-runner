# HUD and in-game UI

**Judging question:** Mid-fight stills and a damage-taken strip. Which HUD looks more polished and readable?

## Pair descriptions

- **Pair 1:** Idle HUD state with hero at rest, showing full health, empty shards counter, no active boons, and no boss bar.
- **Pair 2:** Damage taken - hero taking a hit, health indicator responding, visual feedback evident.
- **Pair 3:** Resource pickup - shard counter updating, visual change to indicate collection.
- **Pair 4:** Upgrade gained - new boon icon added to active boon row, visual state change.
- **Pair 5:** Critical state - low health condition active, visual emphasis on danger state.
- **Pair 6:** Boss encounter - boss health bar displayed, in-combat HUD state during a major fight.
