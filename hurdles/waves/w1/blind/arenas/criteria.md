# Judging criteria: arenas

Question: Stills of several rooms and a door-slam strip. Which levels look more
handcrafted and inviting?

- **Pair 01**: both panels: a static still of an early room, no combat, seen from a
  fixed top-down/three-quarter camera. Stone-and-torch dungeon dressing.
- **Pair 02**: both panels: a static still of a later room with overgrown vegetation
  (moss, vines, foliage) breaking up the stonework.
- **Pair 03**: both panels: a 10-frame burst of real-time combat shortly after a run
  begins, sampled at the same rate on both sides, showing the room composition, hero,
  and enemies together in motion.

Answer A, B, or tie for each pair, then an overall verdict for the packet.
