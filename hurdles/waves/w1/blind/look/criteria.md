# Judging question

Still frames and a slow pan strip. Which one looks like a finished, beautiful game?

Answer `A`, `B`, or `tie` (a tie only if genuinely indistinguishable in quality).

# Pairs

1. Both panels: a still of a lit dungeon room in play, with the player character near its centre, interface hidden or cropped.
2. Both panels: a still of a combat moment in an arena, with the game interface visible.
3. Both panels: a 12-frame strip at 7.5 fps of the player fighting in a dark, torch- or lamp-lit area, interface visible (read left to right, top to bottom).
4. Both panels: a 12-frame strip at 7.5 fps of the camera moving across a room (read left to right, top to bottom).
